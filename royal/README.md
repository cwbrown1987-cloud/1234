# FF: Royal (private)
A personal real-time footy card battler. Not part of Footy Fortress and not published: `deploy.sh` doesn't include this folder.

Play locally: from the repo root run `python3 -m http.server 8080`, then open http://localhost:8080/royal/

Art: drop these in `royal/art/` and they replace the drawn placeholders: `field.webp` (720×1200, 18×30-tile portrait oval), `tower-flank.webp` (160×220), `tower-main.webp` (220×280), `unit-mid.webp`, `unit-fwd.webp`, `unit-ruck.webp` and `unit-def.webp` (128×128). Menus and cards are styled in `royal.css`.
